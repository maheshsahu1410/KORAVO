Great 👍 you’ve listed all important **Cloud Computing viva topics**. I’ll give you **simple, short, exam-ready answers (2–3 lines each)** so you can quickly revise.

---

### 1. Kubernetes

An open-source platform used to **automate deployment, scaling, and management of containers**.

### 2. DevOps

A practice that combines **development and operations** to deliver software faster and more reliably.

### 3. Docker

A tool used to **create, run, and manage containers** for applications.

### 4. Containers

Lightweight packages that include **application + dependencies**, ensuring it runs anywhere.

### 5. Data Governance

Process of managing **data quality, security, and availability** in an organization.

### 6. Data Migration

Transferring data from **one system/storage to another**, often to cloud.

### 7. Scalability & Types

Ability to handle increased load.
Types: **Vertical (increase power)**, **Horizontal (add machines)**.

### 8. Resource Pooling

Cloud provider shares resources among users using **multi-tenant model**.

### 9. Rapid Elasticity

Resources can be **quickly increased or decreased** based on demand.

### 10. Multicloud & Community Cloud

* Multicloud: Using **multiple cloud providers**
* Community cloud: Shared by **organizations with common goals**

### 11. Pros & Cons of Cloud Computing

* Pros: Cost-effective, scalable, flexible
* Cons: Security concerns, internet dependency

### 12. Deterrent Control

Prevents issues before they happen (e.g., **warnings, policies**).

### 13. Corrective Control

Fixes issues after they occur (e.g., **backup recovery**).

### 14. CDN (Content Delivery Network)

Distributes content via **multiple servers** to improve speed and performance.

### 15. Fault

An error or failure in system components that may cause issues.

### 16. Load Balancing

Distributes traffic across servers to **avoid overload and improve performance**.

### 17. Microservices

Architecture where application is divided into **small independent services**.

### 18. NoSQL

Non-relational database used for **flexible and large-scale data** (e.g., MongoDB).

### 19. Replication

Copying data across servers to ensure **availability and reliability**.

### 20. CSP (Cloud Service Provider)

Company providing cloud services (e.g., AWS, Azure).

### 21. Private IP vs Public IP

* Private IP: Used **inside network**
* Public IP: Accessible **over internet**

### 22. BaaS (Backend as a Service)

Provides backend services like **database, authentication, APIs**.

### 23. Cloud Founders

Companies/people who developed cloud platforms (e.g., Amazon, Google).

### 24. CMP (Cloud Management Platform)

Tools used to **manage multiple cloud services** from one place.

---

### 25. Cloud Migration

Process of moving applications/data **to cloud environment**.

### 26. Cloud Washing

False claim of a service being “cloud” when it’s not truly cloud-based.

### 27. CRM Model

Customer Relationship Management model used to **manage customer interactions**.

### 28. Host Machine

Physical computer that runs **virtual machines**.

### 29. Multi-tenancy

Multiple users share the same system **securely and efficiently**.

### 30. Open Source / OpenStack

* Open source: Free and modifiable software
* OpenStack: Open-source cloud platform

### 31. Vendor Lock-in

Dependency on one cloud provider making it **hard to switch**.

### 32. Virtual Cloud VM

Virtual machine running in cloud acting like a **real computer**.

### 33. Agility

Ability to **quickly adapt and deploy changes** in cloud.

### 34. Disaster Recovery

System to **recover data/services after failure**.

### 35. Blockchain

Decentralized ledger used for **secure and transparent transactions**.

### 36. Cloud Bursting

Using **extra cloud resources during peak demand**.

### 37. Cloud Native

Applications built specifically for **cloud environments**.

### 38. Edge & Grid Computing

* Edge: Processing near data source
* Grid: Combining multiple computers to solve problems

### 39. Serverless Computing

Run applications without managing servers; cloud handles everything.
